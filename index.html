04 — Work

Selected projects

Systems I designed and shipped end to end.

PROJECT 01 Live

Agentic Profile Manager

An event-driven multi-agent platform that turns a resume into a structured career profile, then tailors it per target role, checks ATS readiness against a job description, publishes a portfolio site from it, and tracks applications, recruiters and interview prep in one workspace.

Three LangGraph agents do the work: a parser extracts structure from raw PDFs, a generator engineers a responsive single-page site from the JSON profile, and a deployer uses OAuth to create the GitHub repository, commit the source and trigger a live deployment.

Long LLM runs used to die on 504 gateway timeouts, so I decoupled ingestion from processing entirely: Redis brokers the queue and Pub/Sub streams each agent's reasoning back over SSE, letting workers think for as long as they need while the UI stays responsive. Ships to AWS ECS Fargate through GitHub Actions and ECR.
